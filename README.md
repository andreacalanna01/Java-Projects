# 🏛️ CAF & Patronato Enterprise Command Center

![Java](https://img.shields.io/badge/Java-17%2B-orange?style=flat-square&logo=openjdk)
![UI](https://img.shields.io/badge/UI-Java%20Swing%20%2F%202D-blue?style=flat-square)
![Architecture](https://img.shields.io/badge/Architecture-OOP%20%2F%20SOLID-green?style=flat-square)

An enterprise-grade Java desktop application designed for central management and real-time tracking of tax, social security, and welfare applications in a CAF/Patronato service center.

The system combines a robust **Object-Oriented (OOP)** architecture based on **SOLID** principles with a **multithreaded simulation engine** and an interactive dashboard built using **Java Swing** and advanced **Java2D** vector graphics.
